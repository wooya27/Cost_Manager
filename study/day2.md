## 1. `df.shape` — 표의 "크기 쪽지" 🆕 (❗오늘 제일 헷갈림)

`df.shape`는 표가 **몇 행 몇 열인지** 알려준다. 결과는 이렇게 생김:

```
df.shape  →  (15, 8)      # (행 개수, 열 개수)
```

### 핵심 1) 대괄호 숫자는 "값"이 아니라 "몇 번째 칸이냐(위치)"
```
df.shape  →  (   15   ,    8   )
                 ↑          ↑
               [0]칸      [1]칸
```
- `df.shape[0]` → 0번 칸 → **15** (행 개수)
- `df.shape[1]` → 1번 칸 → **8** (열 개수)

👉 내가 실수한 것: `df.shape[15]` 라고 씀.
→ `15`는 **결과값**이지 위치가 아니다. 위치는 `0`, `1`만 있다.
`[15]`라고 쓰면 "16번째 칸 줘"라는 뜻이라 **에러**.

### 핵심 2) `shape`에는 칸이 딱 **2개**뿐 — 대괄호는 한 번만
```python
df.shape[0]   # ✅ 15 (하나 꺼냄, 끝)
df.shape[0][1][2]...   # ❌ 에러! 대괄호 줄줄이 X
```
- `shape` 안엔 오직 2칸(행 개수 하나, 열 개수 하나)뿐. `[2]`, `[3]`... 은 없다.
- `[0][1][2]` 처럼 붙이면 "15를 꺼낸 뒤 그 15에서 또 꺼내라"는 뜻 → 15는 그냥 숫자라 안엔 꺼낼 게 없어서 에러.

### 핵심 3) `shape[0]`은 "0번째 줄 데이터"가 아니라 "줄이 몇 개인지 **개수**"
- ❌ 오해: 15개 행을 하나씩 돌아야(루프) 하나?
- ✅ 사실: `shape`는 이미 세어둔 **개수 숫자**다. 루프 필요 없음.
- **비유:** 식당 손님 수 셀 때, 한 명씩 인터뷰(루프)하는 게 아니라
  입구의 "현재 15명" 팻말을 그냥 읽는 것 = `shape[0]`.
- 실제 데이터 전체를 보고 싶으면 그건 `st.dataframe(df)`가 이미 다 보여준다.

**한 줄 암기:** `shape[0]`은 행 개수, `shape[1]`은 열 개수. 대괄호는 딱 한 번, 칸은 2개뿐.

## 2. `df` vs `st` — 앞에 뭘 붙이지? 🆕 (❗헷갈림)

| 앞에 붙이는 것 | 언제 | 뜻 |
|---|---|---|
| **`st.`** | **화면**에 보여주거나 버튼 만들 때 | **st**reamlit = 화면 담당 |
| **`df.`** | **데이터(표)** 자체한테 뭔가 물어볼 때 | **d**ata**f**rame = 표 데이터 |

**외우는 법: `st` = 화면, `df` = 데이터.**

```python
st.write(...)      # 화면에 뿌려 → st
st.dataframe(df)   # 화면에 표 그려 → st
df.shape           # 표가 몇 행몇 열? → df
df.columns         # 표의 컬럼 이름 → df
```

👉 한 줄에 둘이 같이 나오는 게 정상:
```python
st.write("행", df.shape[0])
#  ↑화면에 보여주는건 st   ↑표한테 행 개수 묻는건 df
```
헷갈릴 때 스스로 질문: **"화면에 뿌리는 동작?" → st / "표한테 묻는 것?" → df**
