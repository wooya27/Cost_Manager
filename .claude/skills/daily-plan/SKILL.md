# 오늘 할 일 뽑기 (daily-plan)

AuditFlow AI 상세계획(`.claude/plans/상세계획.md`)에서 **지금 어디까지 했는지** 확인하고,
**오늘 날짜의 블록 전부**를 `todayplan.md`에 뽑아 적어준다.
단, 압도되지 않게 그중 **"지금 할 1개"를 👉 표시**해서 집중 대상을 명확히 한다.

## 파일 역할
- **원본 지도:** `.claude/plans/상세계획.md` — **Day 1~15 블록** 구조(채용공고 기술스택 반영판). 각 Day는 `## Day N — ...` 섹션이고 그 안에 "오늘 할 일 3개"와 "30분 단위 실행표"(블록=20~40분 작업 1개)가 있다. 날짜→Day 매핑은 이 문서 **"6. 압축 일정"** 표에 있다. "무엇을 만들지"의 출처.
- **옛 계획(참고용):** `.claude/plans/상세계획_OLD_9-5마감.md` — 9/5 마감 구버전. 새 계획으로 대체됨. 평소엔 보지 않는다.
- **기획 근거:** `.claude/plans/`(문서 세트, [`README.md`](../../plans/README.md) 인덱스) — 왜 이렇게 만드는지(요구사항·기능·아키텍처). 블록 의미가 헷갈릴 때 참고.
- **일일 작업지:** 프로젝트 루트 `todayplan.md` — 오늘 날짜의 블록 전부 + 지금 할 1개 표시.

## 순서 (이대로)
1. **현재 진도 파악:** `todayplan.md`의 완료 상태 + `git log --oneline -10` 으로 지금 어디까지 했는지 먼저 확인한다. 추측하지 않는다.
2. **오늘 담당 Day 찾기:** `상세계획.md`의 **"6. 압축 일정"** 표에서 오늘 날짜 행(예: `| 9/6 (일) | Day5 전체 + Day6 블록1 | 4 |`)을 찾아 오늘 처리할 **Day(들)**를 확인한다. 이월된 미완료 블록이 있으면 맨 위에 얹는다. (표에 오늘 날짜가 없으면 = 마감일 이후이거나 여유일이니, 그 사실을 알려주고 남은 미완료 Day를 순서대로 이어서 잡는다.)
3. **오늘 블록 전부 뽑기:** 오늘 담당 Day의 `## Day N — ...` 섹션에서 **"30분 단위 실행표"의 각 행을 블록 1개로** 가져온다("오늘 할 일 3개"는 그 요약이니 블록 이름에 활용). "Day6 블록1"처럼 일부만 지정됐으면 그 실행표에서 해당 순번 행만 뽑는다. 이미 끝난 블록은 "완료" 섹션에, 아직 안 한 블록은 순서대로 "오늘 할 일"에 적는다.
4. **지금 할 1개 표시:** 아직 안 한 블록 중 **맨 앞 1개**에 `👉 지금 이거` 표시를 붙여 집중 대상을 명확히 한다.
5. **todayplan.md에 적기:** 아래 형식으로 오늘 블록 전부를 `todayplan.md`에 쓴다.
6. **학습 대상 구분:** 각 블록이 규칙 엔진 같은 **학습 대상**이면 `🧠 직접 작성`, 설정·보일러플레이트면 `🔧 세팅`으로 표시한다 (CLAUDE.md 규칙).

## todayplan.md 형식
```
# 오늘 할 일 (7/27 월 · N블록)

> 오늘 블록은 다 적어뒀다. 순서대로 위에서부터. 지금 집중할 건 👉 표시된 1개.

## 블록 1 (20~30분) — [무슨 작업] · [🧠 직접 작성 / 🔧 세팅]  👉 지금 이거
- [ ] (할 일 1)
- [ ] (할 일 2)
- 끝나면 보여야 할 결과:

## 블록 2 (20~30분) — [무슨 작업] · [🧠 직접 작성 / 🔧 세팅]
- [ ] ...
- 끝나면 보여야 할 결과:

(... 오늘 블록 전부 ...)

---
## 완료
- [x] (날짜) 이미 끝난 블록
```

## 주의
- 오늘 블록은 다 적되, **말로 안내할 때는 👉 표시된 1개에만 집중**시킨다. "나머지는 그거 끝나고 보면 돼"라고 한 줄 덧붙인다.
- 일을 키우려 하면(오늘 범위 밖 작업) "지금은 확장 금지, 오늘 블록만 닫기"라고 말해준다.
- `상세계획.md`·`.claude/plans/` 기획 문서 세트는 원본 지도이므로 함부로 바꾸지 않는다. 계획 자체가 바뀔 때만 사용자 확인 후 수정한다.
- 블록 완료 때마다 `todayplan.md`를 `- [x]`로 체크하고 "완료" 섹션으로 옮긴 뒤, 다음 블록에 👉 표시를 옮긴다.
- 절대 안 버리는 5개(7종 위험 탐지·규정 근거 검색·보완 요청 초안·결과 다운로드·발표 스크립트)는 뒤로 미루지 않는다. 막히면 상세계획 "12. 막혔을 때 줄이는 기준" 표대로 완성 기준을 낮춘다.
