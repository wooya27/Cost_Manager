## 30분 블록 사용법

한 블록을 다음처럼 사용한다.

```text
약 20분
→ 구현 / 수정

약 5분
→ 실제 실행 / Swagger / DB / 로그 확인

약 5분
→ 무엇을 했는지 기록 + Git 상태 확인
```

> 한 블록에서 완벽하게 이해하려고 멈추지 않는다.  
> **현재 기능을 이해할 만큼만 배우고 → 실행 → 결과 확인 → 다음 블록**으로 간다.

## 블록 완료 판정

각 블록은 아래 셋 중 하나로 끝낸다.

```text
✅ 완료
→ 기대 결과가 실제로 보임

⚠️ 부분 완료
→ 기능은 있지만 검증이 덜 됨

❌ 막힘
→ 오류 메시지 + 시도한 것 + 다음 확인 위치 기록
```

**❌ 막힘 상태로 2블록 이상 같은 문제에 머물지 않는다.**  
2블록을 넘기면 원인을 기록하고, 다음 핵심 기능으로 이동한 뒤 마지막 버퍼에서 돌아온다.

# 5. 5일 후 내가 설명할 수 있어야 하는 최종 문장

> AuditFlow AI는 비용 검수 업무에서 반복적으로 발생하는 위험 확인, 규정 검색, 보완 문구 작성 과정을 자동화하고 최종 판단은 사람이 담당하도록 설계한 AX Workflow 프로젝트입니다. 비용 데이터는 FastAPI에서 검증된 뒤 Python 업무 규칙으로 위험을 탐지하고, pgVector RAG로 관련 규정을 검색해 LLM 초안 생성에 사용합니다. 처리 결과는 PostgreSQL에 저장하고 담당자가 Review API로 최종 상태를 변경합니다. 복잡한 조건 분기와 실패 복구는 LangGraph로 관리하고, Google Sheets → n8n → Cloud API → Slack 흐름으로 실제 업무 자동화를 연결했습니다. 또한 정답표 기반 회귀 테스트, RAG Hit@3 평가, pytest/CI, Docker 재현성, Cloud 배포까지 검증했습니다.
