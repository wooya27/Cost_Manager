## Block 5 — Keyword vs Vector 평가

테스트 질문 약 10~15개를 만든다.

### 예시

```text

"저녁 식사 금액이 너무 큼"

```

### 비교

```text
Keyword Top3
→ 정답 없음 ❌

Vector Top3
1. 식대 한도 규정 ✅
2. 야근 식대
3. 영수증
```

## Block 6 — Hit@3 계산

### 쉽게

> Top 3 검색 결과 안에 정답 규정이 들어왔는가?

### 예시

```text
테스트 질문 = 15개

Keyword
9/15 성공
Hit@3 = 60%

Vector
14/15 성공
Hit@3 = 93%
```

정확한 숫자가 중요한 게 아니라 **직접 평가했다는 사실**이 중요하다.

### Day3 완료

```text
Keyword Search
vs
Vector Search
↓
10~15개 테스트셋
↓
Hit@3
↓
README에 결과 기록
```

### Day3 면접 설명

> Vector DB를 단순 적용하는 데 그치지 않고 테스트 질의셋을 만들어 Keyword 검색과 Vector 검색의 Top-3 검색 성공률을 비교했습니다.


### Day4 면접 설명

> 조건 분기가 증가하면서 LangGraph로 Workflow 상태를 관리했고, 각 실행에 run_id를 부여해 Node별 latency와 오류를 추적했습니다. LLM timeout 시에는 재시도 후 Template fallback으로 이어지도록 설계했습니다.
